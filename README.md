# SQL Filtering Practice

## Project Overview
This project focuses on practising SQL filtering techniques using a sample Northwind-inspired orders dataset.

The main objective is to retrieve specific records using different SQL filtering operators.

## Dataset Details
- Dataset: Northwind Orders Practice
- Total Records: 30
- Database: MySQL
- Table Name: orders_data

## SQL Concepts Used
1. WHERE – Filters records based on conditions.
2. IN – Filters records matching multiple values.
3. BETWEEN – Retrieves records within a specified range.
4. LIKE – Searches for specific text patterns.
5. AND – Combines multiple conditions.

## Tasks Completed
- Filtered orders by country.
- Retrieved shipped orders.
- Filtered multiple product categories.
- Selected orders within quantity and price ranges.
- Filtered orders by date.
- Searched customer and product names using LIKE.
- Retrieved pending and cancelled orders.
- Combined multiple filtering conditions.
